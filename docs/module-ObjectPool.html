Class: module:ObjectPool

module:ObjectPool(capacity, presetCreater)

- 使用されたオブジェクトの参照を管理し、生成の代わりに参照を使いまわします. - Character, Bulletを生成又は削除したい場合、new, deleteは使わないでください

Example
const fishPool = new ObjectPool(100, () => new Fish()); // new Fish()を初期値としてサイズ100のプールを生成
const fish = fishPool.get(); // 使われていない参照を取得
fish.reset(size, weight) // Fishクラスにリセット用メソッドを実装
